## Current work

I own [Kruoop.com](https://kruoop.com), an AI learning platform and community, and [Seeneo.ai](https://seeneo.ai), an AI video editor. My open-source work covers Claude Code skills, ERP, and Thai dialect speech recognition.

## Flagship projects

- [claude-thai-skills](https://github.com/Boom-Vitt/claude-thai-skills) gives Claude Code 12 skills for Thai-language tasks.
- [boombignose-erp](https://github.com/Boom-Vitt/boombignose-erp) is an open-source ERP under AGPL-3.0.
- [thai-dialect-asr](https://github.com/Boom-Vitt/thai-dialect-asr) reports Pattani Malay CER of 12.71 versus 65.05 for the best open model, measured with [eval_v2](https://github.com/Boom-Vitt/thai-dialect-asr#วัดผลด้วย-eval_v2).
